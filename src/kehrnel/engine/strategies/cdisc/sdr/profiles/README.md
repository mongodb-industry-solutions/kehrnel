# CDISC repository profiles

Profiles do not create separate repository products. They select deterministic
facets, entity relationships, validation expectations, query indexes, and
materialized views over the same lossless canonical record contract.

`catalog.json` is the deployment-visible capability declaration. Exact domain
support and conformance depend on the registered standards and rule package;
the synthetic domain lists are demonstration datasets, not claims that the
listed domains constitute an entire implementation guide.
