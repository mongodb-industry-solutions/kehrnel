Embedded CLI Demo for the openEHR RPS Dual workflow

This page is a test bed for the terminal-first demo experience. The goal is to see whether internal users can understand the openEHR data model, strategy activation flow, and runtime capabilities through a guided CLI without building a large custom portal.

Start here

  1. Step 1 Use the terminal as if it were a guided lab. It opens in a preconfigured tmux session.
  2. Step 2 In the left pane, type demo-runtime to start the Kehrnel runtime on port 8080.
  3. Step 3 In the right pane, type demo-help and then demo-smoke.
  4. Step 4 If you want to explore beyond the smoke flow, use demo-assets, demo-explore, and demo-status.

If MONGODB_URI or BINDINGS_REF was not configured when the stack started, the shell still supports template generation, validation, flattening, strategy discovery, and documentation exploration. Runtime-backed activation and query execution become available once bindings are supplied.
